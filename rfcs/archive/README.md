# Archived RFCs

**State: withdrawn, or superseded by a later RFC. Preserved as evidence the discussion happened.**

Part of the lifecycle in [RFC-000](../done/000-rfc-lifecycle-policy.md), extended to the 5-folder
variant by [RFC-092](../done/092-five-folder-rfc-lifecycle.md).

```
proposed/  ← under review
accepted/  ← signed off, implementation authorized
done/      ← shipped
archive/   ← HERE: withdrawn or superseded
```

## What belongs here

- **Withdrawn.** The author or maintainer decided not to pursue it. Status says `Withdrawn`, with the
  reason **in the file**.
- **Superseded.** A later RFC took over its design space. Status says `Superseded by RFC-NNN`, and
  the newer RFC carries a reciprocal note pointing back — RFC-000's own convention.

There is deliberately **no "rejected" state**. An RFC the maintainer declines is archived with a
reason, because the file is evidence that the question was asked and answered.

## What does not

- **Numbers are never reused.** An archived RFC keeps its number; the next new RFC takes the next
  one. RFC-098 sitting here does not free `098`.
- **Nothing is deleted.** If a decision here turns out to be wrong, a *new* RFC reverses it and says
  so. Editing an archived file to change what was decided would falsify the record.

**An empty directory here is normal.** It means nothing has been withdrawn or superseded yet — which
was true of this project until 2026-08-04.
